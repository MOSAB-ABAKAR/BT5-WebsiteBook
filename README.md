## BT5 – Website Book

A responsive book landing page built with HTML5, CSS3, and Bootstrap 5. This project showcases a modern promotional website for the fictional "Net Ninja Pro – The Book", featuring book information, pricing plans, reviews, and contact sections.

## Live Demo

View the Website

 ## Features
Responsive Navigation: Mobile-friendly navigation bar with Bootstrap.
Hero Section: Book introduction with a cover image and call-to-action button.
Pricing Plans: Three editions with different pricing options.
Book Contents: Accordion displaying six learning chapters.
Book Reviews: Customer review section with star ratings.
Contact Form: Form for visitors to send questions.
Newsletter Modal: Pop-up for registering for updates.
Offcanvas Sidebar: Explore other recommended books.
Bootstrap Tooltips: Interactive information hints.

 ## Getting Started
1. Clone the repository
bash
git clone https://github.com/MOSAB-ABAKAR/BT5-WebsiteBook.git

2. Navigate to the project folder
bash
cd BT5-WebsiteBook

3. Run the website

Open index.html in your web browser.

You can also use the Live Server extension in Visual Studio Code for local development.
